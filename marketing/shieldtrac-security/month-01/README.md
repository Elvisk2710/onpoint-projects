# ShieldTrac Security — undated Month 1

30 original posts with finished feed and Story PNGs, editable SVGs, channel-specific captions, alt text, four five-slide carousels, one image-generated educational poster, weekly article drafts and real-media reel scripts.

1. Review `calendar.csv` and `captions.md`. Map Day 1 to a Monday; this is a 30-day sequence, not a dated recurring automation.
2. Use `images/feed/day-NN.png` or `images/story/day-NN.png`. On Days 2, 9, 16 and 23 you can publish the complete five-slide carousel instead.
3. The image-generated poster is in `images/generated/`; it is an additional option for Day 6. Its aspect ratio is approximately 4:5; original file is preserved.
4. Edit vector artwork in `editable/` using an SVG editor. Confirm line wrapping after font changes.
5. Use `articles.md` for weekly website articles and `real-media-production.md` for authentic project/team content.

## How this adapts the source plan

The original 30-day plan remains unchanged. Where it requests an actual job, testimonial, employee profile, current offer or deadline, this pack supplies a finished evergreen educational alternative. Replace that card with approved real media using the production sheet when available. Seasonal December/festive deadlines, discounts, free assessments and unsupported promises are deliberately absent from the undated pack. No public posts have been made.
